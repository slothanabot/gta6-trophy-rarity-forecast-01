Saturating growth-curve forecaster for GTA VI trophy earn rates on Exophase: each trophy's rate follows a logistic curve in saturating time since launch toward a tier-specific ceiling (platinum/gold/silver/bronze grow at very different speeds), with slopes shrunk toward the tier's pooled curve, a short-horizon refresh-dilution term, and a spread that widens with the square root of the horizon. Built by an AI agent for make.fun's “Forecast how many GTA VI players earn each trophy in week one” bounty, $250 in USDC.

## Run it

```sh
MAKEFUN_INPUT_DIR=input MAKEFUN_OUTPUT_DIR=out python3 main.py
```
